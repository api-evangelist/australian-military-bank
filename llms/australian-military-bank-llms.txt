# Australian Military Bank

> Australian Military Bank Ltd (ABN 48 087 649 741, AFSL/Australian Credit Licence 237988, BSB 642170) is a customer-owned mutual authorised deposit-taking institution (ADI) serving the Australian Defence Force community since 1959. As a CDR data holder its only public, unauthenticated API is the mandated Consumer Data Right (CDR) Product Reference Data (PRD) API, built to the Data Standards Body (DSB) Consumer Data Standards. Consumer data sharing (accounts, balances, transactions) is available only to CDR-accredited data recipients over authenticated, FAPI-profiled OAuth2/OIDC flows.

## APIs

- [CDR Product Reference Data API](https://www.australianmilitarybank.com.au/consumer-data-right): Public, unauthenticated product catalogue. Base URL https://public.open.australianmilitarybank.com.au/cds-au/v1 — GET /banking/products and GET /banking/products/{productId}. Send header x-v: 3.
